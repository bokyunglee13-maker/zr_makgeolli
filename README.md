# ㅈㄹ막걸리 × DOOTA 팝업

다국어(한·영·일·중) 팝업 이벤트 사이트. 정적 HTML + Google Apps Script/구글시트 백엔드 + Vercel 배포.

> 📖 **모든 내용은 [`정본/`](정본/README.md) 에 있습니다** — 표지/한장요약 → 개요·구조 → 디자인 → 변경이력 → 할일.
> 🤖 작업 규칙·명령어·라우팅은 [CLAUDE.md](CLAUDE.md).

빠른 배포: Apps Script 웹앱 URL을 index/survey/name의 `CONFIG.WEBAPP_URL`에 입력 → GitHub push → Vercel(Framework: Other). 상세는 [정본/01-개요와구조](정본/01-개요와구조.md) §7.

⚠️ 형제 레포 `../zr-editions`(POLYC 에디션)는 **별도 레포·별도 배포**. 이 레포는 두타몰 사이트 전용.
