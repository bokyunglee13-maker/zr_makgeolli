## 운영 주의점 (Gotchas)
- ⚠️ **DOM 요소 삭제 시 그 요소를 참조하는 JS도 같이 제거/가드(`if(el)`) 필수.** `getElementById('없는id').addEventListener(...)`가 null 에러를 던지면 **그 줄 이후 스크립트 전체가 중단** → 맨 끝 `applyLang()` 초기화·핸들러가 안 붙어 **i18n 미적용(기본 텍스트 노출)·언어토글·폼 전부 먹통**. **증상이 "번역 안 되고 기본 텍스트만"이면 콘솔 에러부터 확인.**
- **페이지마다 `CONFIG` 존재 확인.** name.html은 원래 CONFIG가 없어 시트 로깅이 조용히 실패한 전례 → 새 페이지 추가 시 CONFIG 확인.
- **전역 함수명 네이티브 충돌 주의.** `open` 등은 `window.open`과 충돌 → 고유 이름.
- **Canvas 폰트**: 그리기 전 `document.fonts.load('900 …px Paperlogy')` + `document.fonts.ready` await. 보틀 이미지도 onload await. 한글 캔버스 텍스트는 Paperlogy(Space Mono·Archivo는 한글 글리프 없음).
- **인스타 공유**: Web Share API(files) — 모바일만 공유시트, 데스크톱 다운로드 폴백. 자동 게시 불가.
- **이미지 경로는 `/assets/...`(루트 절대).** 하위경로 라우트에서 상대경로 깨짐 방지.
- **대용량 원본**: `_originals/`(56MB png 등) gitignore. 신규 이미지는 웹 최적화(PIL 등) 후 assets에. `makku.jpg`는 워터마크 제거·최적화본.
- **로컬 미리보기**: 이 환경의 `python`은 MS Store 스텁(가짜) → **node** 사용. `.claude/serve.cjs`(static 5510). `.claude/`는 gitignore(로컬 전용).
