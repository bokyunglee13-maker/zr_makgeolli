## zh(중국) 小红书 현지화 — 왜 이렇게 했나
중국은 인스타 불가 → zh 버전만 **小红书(RED)** 흐름. 헤더·배너 "小红书认证", **快拍(스토리)→笔记(피드 포스트)**, 태그(`#韩国旅游 #韩国旅行 #韩国米酒 #首尔美食 #首尔必吃` + DOOTA 地点).
- **계정: ID(小红书号) `Tipsyrice` / 닉네임 `Makgeolli lover`.**
- ⚠️ **왜 검색·팔로우·푸터는 ID로?** 小红书号(ID)는 **유일**하지만 닉네임은 **중복 가능**(동명이인·사칭) → 닉네임 검색은 엉뚱한 계정이 뜰 수 있어 **반드시 유일 ID `Tipsyrice`**. @멘션(笔记)만 닉네임 `@Makgeolli lover` 불가피(小红书 @는 닉네임으로만 동작).
- 팔로우 링크 언어 분기: `applyLang()`에서 `lang==='zh' ? CONFIG.XHS_URL : CONFIG.INSTA_URL`. `XHS_URL = search_result?keyword=Tipsyrice`(**검색 딥링크** — 小红书 웹→앱 링크가 불안정해 프로필 URL 대신 ID 검색 유도, 의도된 선택). 푸터 SNS도 동일 분기(zh="小红书 Tipsyrice"). 다른 언어(ko/en/ja)는 Instagram 유지.

## 버그 히스토리 (해결됨)
- **초성 엔진 변환 버그**: 모든 coda 누락(d/t/k)→`CODA` 도입 / 모음연속 ㅇ과잉(seo·young)→`VOWEL_DI` / 어말 ㅋ '크'음절→CODA에 ㅋ / `ou` 양면성(young 병합 vs soul 분리)→`soul`만 NAME_MAP / `amy`·`nicole`→en `silentE`. (이후 index/name 중복 로직을 `chosung.js` 한 파일로 추출.)
- **DOOTA 글자 간격**: 두 span으로 쪼개면 글자 사이 떠 보임 → `.doota` 단일 그라데이션으로 해결.
- **name.html CONFIG 누락**: `logName`의 `CONFIG.WEBAPP_URL`이 ReferenceError로 시트 로깅 조용히 실패 → name.html에 CONFIG 추가. (교훈: 페이지마다 CONFIG 존재 확인.)
- **함수명 네이티브 충돌**: name.html 생성기 함수 `open`이 `window.open`과 충돌 → `openCard`로 리네임.
- **요소 삭제 시 참조 JS 미제거**로 스크립트 중단(개인정보 동의·`gift-insta` 삭제 때) → 리스너를 `if(el)` null-safe로. (상세 주의는 [04-할일과참고](04-할일과참고.md).)
